StreamGuard — Real-Time Deepfake Audio Detection

End-to-end streaming inference system classifying live audio as REAL / UNCERTAIN / FAKE with calibrated confidence — built for live calls and streaming media where milliseconds matter.

  • dual-branch encoder: causal waveform CNN ⊕ multi-res mel-spectrogram CNN, learned gating
  • MC-Dropout over sliding windows → calibrated 3-state verdict, not naive binary
  • FastAPI WebSocket + ONNX on CPU — target P95 < 80 ms, RTF < 0.15
  • leakage-free cross-dataset eval (ASVspoof 2019 LA → 2021 DF): EER, ROC-AUC, ECE + Grad-CAM

S — deepfake speech is nearly indistinguishable from real audio; most detectors run offline, unusable for live media.

T — design a streaming real-vs-spoof classifier with calibrated confidence and interpretable outputs.

A — dual-branch streaming encoder, uncertainty-aware temporal aggregation, ONNX/WebSocket serving, Grad-CAM + Next.js verdict UI.

R — deployable system with quantified latency & calibration targets; training, eval & deployment pipelines open-sourced.

DocMind — AI Document Intelligence Platform

Multi-tenant RAG document-QA platform with a measurably better hybrid retrieval pipeline and a reproducible evaluation harness.

  • hybrid retrieval: pgvector cosine ⊕ PostgreSQL full-text, fused via Reciprocal Rank Fusion
  • LLM reranking — Gemini Flash re-scores top-20 → top-5, fixing the "answer buried at rank 12" failure
  • ingestion: PDF → 600-word semantic chunks → Gemini embeddings → pgvector IVFFlat + RLS isolation
  • inline [n] citations in a streaming chat UI + LLM-judge eval harness (1–5)

S — naive vector-only RAG buries correct answers at low ranks, with no measurable evidence of retrieval quality.

T — build a document-QA platform with a provably better retrieval pipeline.

A — hybrid + RRF retrieval, LLM reranking, durable async ingestion (Inngest), serverless deploy on Vercel.

R — live deployed platform; hybrid+rerank scored meaningfully higher than vector-only on the harness.

Promo Planner Agent — Multi-Agent Campaign Generator

A supervisor-based multi-agent system that turns a product brief into a validated promotion plan — LLM agents generate, a Python validator (not the LLM) decides.

  • supervisor orchestrator: Research ⊕ Audience run in parallel → Strategy → Creative → Critic
  • critic-driven revision loop with a hard cap (max 2) feeding issues back upstream
  • grounded research: claims traced to live Tavily web sources — no invented URLs
  • pure-Python validation gate: budget = 100%, KPIs, timeline, assets, min-sources
  • loose LLM JSON coerced via Pydantic ("40%" → 40.0) + one retry with the error fed back

S — LLM-generated marketing plans hallucinate budgets and sources; generation and verification live in the same trust domain.

T — architect a multi-agent pipeline where agents propose but only deterministic code accepts.

A — GroqCloud (llama-3.3-70b) reasoning, Tavily research, Pydantic-typed shared CampaignState, Gradio UI, bounded revision loop, Dockerized.

R — validated plans with a numeric score, agent trace and source list; offline pytest suite (fake LLM + fake search) needs zero API keys.

PythonGroqCloudTavilyPydanticGradioDockerpytest

Deepfake Image & Frame Detector

Binary real-vs-fake frame classifier shipped as a complete, reproducible ML pipeline — from dataset ingestion to deployed interactive inference.

  • fine-tuned ResNet-50 (Dropout p=0.3 → 2-class head) via transfer learning
  • cross-entropy + label smoothing · AdamW + weight decay · StepLR on Kaggle GPUs
  • targeted augmentation + stratified splits to fight overfitting & class imbalance
  • Streamlit app applies identical validation transforms — zero train/serve skew

S — synthetic imagery from diffusion/GAN models poses authenticity risks; general classifiers miss fine-grained artifacts.

T — train and deploy a real-vs-fake classifier as a reproducible end-to-end pipeline.

A — transfer learning with custom head, disciplined training loop, augmentation strategy, parity-ensured inference app.

R — working detector with per-epoch curves, classification reports & confusion-matrix evaluation.
